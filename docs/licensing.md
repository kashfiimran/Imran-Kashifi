# Legal & Licensing Guidelines

## Strict Separation of Concerns
1. **Open-Source Runtime**:
   - The runtime bridge, touch controller, WebGPU pipeline, capability detector, and virtual filesystem management are open-source and freely redistributable.
2. **Authorized Game Content**:
   - Proprietary game files (e.g. `GTA5.exe`, `update.rpf`, audio streams, textures) belong exclusively to Take-Two Interactive Software, Inc. and Rockstar Games.
   - This application does NOT host, download, crack, or distribute copyrighted assets or bypass digital rights management.
   - Users can mount their legally owned PC copy via the browser's standard File System Access API.
